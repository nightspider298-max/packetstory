# Security Policy

PacketStory is a defensive offline analysis tool. It parses untrusted capture files and does not transmit data to external services.

Please report security issues privately to the repository maintainers rather than filing a public issue with a weaponizable capture or exploit. Include the affected version, a minimal reproduction, and impact. Do not include sensitive packet contents.

Supported release line: `0.1.x` (best effort while the project is in alpha).
